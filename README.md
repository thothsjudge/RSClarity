# RSClarity
RSClarity is a desktop automation tool that simulates repeatable mouse actions with human-like timing. Configure CPS ranges, run duration, and action limits, record your own CPS, target a custom screen area, and use the built-in calculator—plus Anti-Detection, jitter and configurable click rates.  and global hotkeys for precise, flexible control. It is designed for stress-testing, repetitive workflows, and input automation on Windows.

Key Features

CPS overrides (per minute, per second, per ms) and CPS range with priority logic.

Run Duration timer (H:M:S) with pause-aware countdown.

RSClarity Limit counter that stops automatically after a chosen number of actions.

Location Area capture overlay for targeting a custom region of the screen.

Optional Anti-Detection jitter and micro-delays for more natural-looking input.

Built-in CPS recorder and mini calculator.

# Quick Use

Set your CPS or CPS Range (5–11 by default).

Optionally set Run Duration and/or RSClarity Limit.

(Optional) Use “Record CPS” to measure your natural speed.

Optionally set a Location Area and enable it.

Click Start or press F4. Use F6 to pause/resume and F5 to stop.
